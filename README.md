# قَطفة: موقع قهوة بمقدمة تتحرك مع التمرير

## التشغيل
```
npm install
npm run dev      # للتطوير
npm run build    # نسخة الإنتاج في dist/
```

## أين أعدّل؟
- `src/content.js`: اسم العلامة، نصوص الفصول وأرقام إطاراتها، المنتجات، التاريخ، طرق التحضير.
- `src/styles.css`: الألوان والخطوط في `:root`، وطول تمرير الفيلم في `--intro-length`.
- `src/Intro.jsx`: محرك الفيلم (Canvas + GSAP ScrollTrigger).
- `src/scroll.js`: التمرير الناعم (Lenis).
- `public/frames/`: ٥٩٨ إطار WebP بمقاس 1280×720. لو غيّرت العدد عدّل `FRAME_COUNT` في `content.js`.

## ملاحظات
- ٣٧ إطارًا كانت تالفة في الأرشيف الأصلي، وتم تعويضها بمزج الإطارين المجاورين. أرقامها في `public/frames/manifest.json`. لاستبدالها ضع الإطار الأصلي بنفس الاسم.
- مع `prefers-reduced-motion` تُعرض الصورة الأخيرة ثابتة بدل الفيلم.
- على الموبايل أو الأجهزة قليلة الذاكرة يُحمَّل نصف الإطارات.
